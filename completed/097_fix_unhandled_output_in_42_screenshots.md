# Fix unhandled output in t/42-screenshots.t

The test `t/42-screenshots.t` has unhandled output due to logs generated by `OpenQA::Task::Job::Limit::limit_results_and_logs()`. This breaks `tools/prove_wrapper` which strictly checks for clean TAP output.

## Plan

1. Wrap the calls to `run_gru_job($app, limit_results_and_logs => ...)` that are not already tested for their log output with `Test::Output::combined_from` to suppress the log output and prevent `prove_wrapper` from failing.
2. Update the `Test::Output` use statement to import `combined_from`.
3. Check using `make test-unit-and-integration TESTS=t/42-screenshots.t`
4. Run `make tidy` and `make test-checkstyle`
5. Commit the fix with atomic commit discipline.
